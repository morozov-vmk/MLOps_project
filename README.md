# Cashback Activation Prediction

## Бизнес-цель

**Прогнозирование вероятности активации кешбек-предложений пользователями** для повышения эффективности маркетинговых кампаний и увеличения вовлеченности клиентов.

### Проблема бизнеса
Банк тратит значительные ресурсы на рассылку кешбек-предложений, но только часть пользователей активирует их. Это приводит к:
- Неэффективному использованию маркетингового бюджета
- Раздражению пользователей ненужными предложениями
- Упущенной выгоде от неактивированных кешбеков

### ML-решение
Разработка модели машинного обучения, которая предсказывает вероятность активации кешбек-предложений каждым пользователем, позволяя:
- Персонализировать рассылку предложений
- Увеличить конверсию активаций
- Снизить затраты на маркетинг

## Набор данных

### Источники данных
- **Исторические транзакции** - данные о покупках пользователей
- **Поведенческие метрики** - активность в мобильном приложении
- **Демографические данные** - сегментация пользователей
- **История кешбек-активаций** - предыдущие реакции на предложения

### Структура данных
- **370 признаков** включая:
  - `cat_viewed_cnt_1m` - просмотры категорий за 1 месяц
  - `cat_activated_cnt_3m` - активации за 3 месяца  
  - `transaction_turnover_ratio_6m` - оборот транзакций
  - `cluster_cat_activated_ratio` - активность в кластере
- **Целевая переменная**: `active_essence` (бинарная: 0/1)
- **Объем**: 1M+ записей в тренировочном и тестовом наборах (данные для примера урезаны)

### Предобработка данных
- Очистка от NaN и infinite значений
- Масштабирование числовых признаков
- Автоматическое определение фичей (исключая служебные колонки)

## Целевые метрики

### Бизнес-метрики
- **Увеличение конверсии активаций**
- **Снижение маркетинговых затрат**

### Метрики качества модели
- **AUC-ROC**: ≥ 0.8
- **Precision**: ≥ 0.78 (минимизация ложных срабатываний)
- **Recall**: ≥ 0.72 (охват целевой аудитории)
- **F1-Score**: ≥ 0.75

### Технические метрики
- **Время инференса**: <= 30 мин на выборке из всех пользователей (это оффлайн решение, инференс раз в месяц)
- **Использование памяти**: ≤ 512 GB RAM
- **Время обучения модели**: ≤ 6 часов
